# 1. Область, термины и источники

## 1.1 Область и статус

BL — язык исходных файлов `.bl`, который компилятор Z8 разбирает, проверяет и преобразует в Java для runtime Z8. Встроенная библиотека сама содержит объявления BL с привязками к Java. Язык, библиотека, генератор и поведение SQL-сервера — разные уровни: наличие функции в библиотеке не делает её синтаксисом языка. Документ описывает конкретную исследованную реализацию, а не совместимость всех версий Z8.

В исследованном checkout HEAD `777acbd3b32a94b4cd09b44ba313492189ef3fd8`; рабочее дерево имело изменение `org.zenframework.z8.server/WEB-INF/server.properties` и неотслеживаемый `stats.sh`. Они не служат основанием языковых правил. Других изменений `git status --short` не показал. Содержимое стандартной библиотеки и реализация исследованы преимущественно статически. Дополнительно проведены проверки лексера и BL-компилятора и воспроизводимые испытания с компиляцией и выполнением сгенерированной Java; состав и ограничения — в [разделе 12](12-implementation-evidence.md). Расширенные гарантии совместимости и нерассмотренные крайние случаи в [разделе 10](10-conformance.md).

## 1.2 Термины

| Термин | Значение |
|---|---|
| единица компиляции | исходный файл и связанная с ним запись `CompilationUnit` |
| квалифицированное имя | последовательность идентификаторов, разделённых точкой |
| тип значения, тип переменной | разрешённый тип с нулём или несколькими измерениями массива/карты |
| primary-тип | тип, который компилятор относит к иерархии `primary`; признак и типы не выводятся из написания имени |
| ссылочный тип | по `VariableType.isReference`: не массив, не enum, не наследник `primary` |
| измерение | скобки `[]` для последовательности либо `[K]` для отображения с типом ключа `K` |
| член | поле, метод, оператор или другая сущность типа в контексте соответствующих классов компилятора |
| native | объявление, связанное через атрибут с реализацией Java; это не ключевое слово BL |
| диагностируется | компилятор обнаруживает ситуацию и выдаёт сообщение; вид сообщения — ошибка или предупреждение — уточняется контекстом и исходником |

## 1.3 Обозначения и структура

В EBNF `::=` — определение, `|` — выбор, `[ ... ]` — необязательный фрагмент, `{ ... }` — повторение, `"..."` — терминал. Если квадратные или фигурные скобки являются буквальными символами BL, они заключены в кавычки. Приложение [грамматики](08-grammar.md) сохраняет отдельную yacc-нотацию и явно описывает её ограничения. Разрешение имён, типизация и диагностика являются дополнительными ограничениями и не задаются одной грамматикой.

## 1.4 Источники и проверяемость

Ниже `C` означает `org.zenframework.z8.compiler/src/main/`, `L` — `org.zenframework.z8.lang/src/bl/`, `S` — `org.zenframework.z8.server/src/main/java/` относительно корня Z8. Пути в остальных разделах используют эти обозначения.

| Обозначение | Ответственность |
|---|---|
| `C/grammar/Grammar.y`, `C/java/org/zenframework/z8/compiler/parser/grammar/Grammar.java` | исходная грамматика и сгенерированный parser |
| `C/java/org/zenframework/z8/compiler/parser/grammar/lexer/` | токены, сканирование, литералы и классификация символов |
| `C/java/org/zenframework/z8/compiler/parser/` | дерево, типизация, объявления, выражения и операторы |
| `C/java/org/zenframework/z8/compiler/workspace/` | проекты, пути, разрешение имён, стадии и генерация |
| `L/org/zenframework/z8/lang/` | объявления типов BL, включая native и SQL-типы |
| `S/org/zenframework/z8/server/types/`, `S/org/zenframework/z8/server/runtime/` | Java-типы значений и runtime-объектов/коллекций |

Образцы оформления: [Java Language Specification](https://docs.oracle.com/en/java/javase/26/docs/specs/jls/index.html), [Kotlin specification](https://kotlinlang.org/spec/syntax-and-grammar.html), [C# specification](https://learn.microsoft.com/dotnet/csharp/language-reference/specifications). Они обосновывают организацию материала, но не определяют правила BL.
