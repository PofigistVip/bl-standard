# 12. Проверенные особенности реализации

Здесь собраны результаты, которые особенно важно не смешивать: принятие исходного текста компилятором BL, успешность компиляции сгенерированной Java и фактическое выполнение. Источники: `C/grammar/Grammar.y`, `C/java/org/zenframework/z8/compiler/parser/`, `S/org/zenframework/z8/server/runtime/`, `S/org/zenframework/z8/server/types/`; обозначения и ревизия — в [разделе 1](01-overview.md).

## 12.2 Проверенное окружение

Использован исходный checkout Z8 с HEAD `777acbd3b32a94b4cd09b44ba313492189ef3fd8`, чистые относительно исходников компилятора и runtime файлы; не связанные с этим исследованием изменения checkout перечислены в [разделе 1](01-overview.md). Сборка boot, 626 Java-файлов сервера и 136 Java-файлов компилятора выполнена в изолированном временном каталоге с Eclipse Adoptium JDK 8 и локальным кэшем Gradle, где версии `3.4-cert` ставятся первыми. Готовые `target/classes` сервера и компилятора не используются как классы испытуемого runtime.

Тесты копируют 168 BL-файлов библиотеки во временный проект, добавляют по одному тестируемому классу и необходимые вспомогательные типы, затем запускают свежесобранный BL-компилятор. Для выполняемых случаев `javac` компилирует сгенерированные Java-файлы против свежесобранного сервера, а Java запускает их. Тестовый Java-код задаёт полю `ServerConfig.language` значение `ru` через reflection до инициализации ресурсов: без инициализированной конфигурации отдельный запуск `bool` может завершиться в `Resources` раньше выполняемого BL-примера. Такой запуск не моделирует полностью настроенный сервер, БД и многопоточную работу.

## 12.3 Воспроизведение

Команды для данного рабочего пространства Windows; при другом расположении замените пути:

```powershell
python tests/check_docs.py --z8-root "C:/Users/volod/eclipse/jee-2022-12/z8-homer-workspace/org.zenframework.z8"
python tests/check_parser.py --z8-root "C:/Users/volod/eclipse/jee-2022-12/z8-homer-workspace/org.zenframework.z8"
python tests/compile_probes.py --z8-root "C:/Users/volod/eclipse/jee-2022-12/z8-homer-workspace/org.zenframework.z8"
python tests/runtime_probes.py --z8-root "C:/Users/volod/eclipse/jee-2022-12/z8-homer-workspace/org.zenframework.z8" --jdk8 "C:/Program Files/Eclipse Adoptium/jdk-8.0.362.9-hotspot"
```

`compile_probes.py` компилирует и запускает `LexerProbes.java`, затем проводит проверки BL-компиляции. `runtime_probes.py` требует JDK 8 и локальные зависимости сервера; `--dependency-cache` позволяет задать расположение кэша. Все генерируемые файлы помещаются во временный каталог. При иной версии Java, наборе jar или конфигурации сервера результаты могут отличаться; в таком случае сначала следует проверить окружение, а не заменять описанные наблюдения предположениями.
